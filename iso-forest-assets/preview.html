Putting them on screen

Where a sprite goes

Each sprite has an anchor: the point of its canvas that sits on the centre of a tile. Put the anchor on the tile centre and everything lines up.

// centre of tile (col, row) on an N × N island
const cx = (N + col - row) * 64;
const cy = HEADROOM + (col + row + 1) * 32;

// any sprite, tree or ground
left = cx - sprite.anchorX;
top  = cy - sprite.anchorY;

// paint ground first, then plants,
// each sorted by col + row, smallest first

Which ground piece

Only the two front edges of the island show soil. The right face is its own file because it is shaded darker than the left one.

const last = N - 1;
const piece =
  col === last && row === last ? 'ground_corner'
  : col === last               ? 'ground_edge_right'
  : row === last               ? 'ground_edge_left'
  :                              'ground_top';
